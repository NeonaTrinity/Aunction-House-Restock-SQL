* Caution * This script requires users to edit and replaced the guid of the auction with a player created user account. 
The account does not need to be logged in and the character shpould not be played by anyone on the server.
requires the account to have 2 characters created of any level. *

* script is intended for a server with cross faction auction houses only*

An sql script in development for azeroth core server. Restocks the Auction house with random items with auctions that last 48 hours. 
User can run the script every 48 hours and restart the server to refresh the auction. 
ideal for single player and local network servers that can be rebooted regularyly.

feel free to modify and use this sql to fit your own server however you like.

This uploaded is intended to preserve version history for myself but available publicly if anyone finds it useful.
